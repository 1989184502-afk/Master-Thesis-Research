# Master-Thesis-Research
Machine Learning for Predictive Decision Support: Customer Churn Prioritization and Maritime Survival Prediction
Project Overview

This repository contains the source code, datasets (where redistribution is permitted), and supplementary experimental materials associated with the master's thesis titled "Machine Learning for Predictive Decision Support: Customer Churn Prioritization and Maritime Survival Prediction."

The thesis consists of two independent research studies that explore the application of machine learning techniques to predictive modeling and decision support.

The first study focuses on customer churn prediction and customer value-based prioritization. It develops classification models to identify customers at risk of churn and integrates churn probability with relative customer value to establish a prioritization framework for customer retention.

The second study investigates the application of Automated Machine Learning (AutoML) to maritime disaster survival prediction. Using the Titanic and Estonia datasets, it evaluates AutoML-based model search and compares its predictive performance with conventional machine learning approaches under different search time budgets.

This repository provides the implementation and supporting materials for both studies, including model development, experimental evaluation, and relevant analysis procedures.

The purpose of this repository is to improve research transparency and facilitate the understanding and reproducibility of the experiments presented in the thesis.
